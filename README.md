# NeetCode Submissions

Status: ongoing coding interview practice

This repository contains my synced NeetCode submissions, with a current focus on solving data structure and algorithm problems in Java.

## Why This Repository Exists

I use this repository as part of my preparation for mid-level software engineering interviews. The goal is not only to increase the number of solved problems, but to improve implementation fluency, complexity analysis, edge-case handling, and the ability to explain solutions clearly.

## Current Focus

The public repository currently includes 22 Data Structures & Algorithms problem folders.

Patterns currently represented include:

- Arrays and hashing
- Two pointers
- Sliding window
- Binary search
- Stack
- Dynamic programming basics

## Repository Structure

Solutions are synced from NeetCode and organized by topic folder, then problem ID.

```text
Data Structures & Algorithms/
  two-integer-sum/
    submission-0.java
  is-anagram/
    submission-0.java
  ...
```

The exact filename extension depends on the language used for each submission. My main interview language is Java.

## What I Practice

For each problem, I try to strengthen:

- Choosing the right data structure
- Writing clean Java code under interview constraints
- Explaining time and space complexity
- Checking important edge cases
- Reviewing weak patterns through spaced repetition

## Notes

This repository is synced automatically from NeetCode. Some files may represent raw submissions rather than polished standalone solutions.

For a portfolio or interview review, the most useful signal is the progression of solved patterns and Java implementation practice, not perfect repository formatting.
